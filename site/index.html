relate-gram

Load gram files into a Relate graph database, and export a Relate database as gram.

GitHub Releases Quickstart What is supported

Gram is a plain-text notation for graphs. relate-gram supports a strict subset: the constructs that map directly to Cypher's property graph model (nodes, relationships, paths and the top-level record). Anything else is rejected with an error that says what it is and where it is, and relate-gram fix corrects the mechanical cases.

A file

(ada:Person {name: "Ada"})
(grace:Person {name: "Grace"})
(ada)-[:KNOWS {since: 1843}]->(grace)

Five commands

relate-gram check people.gram                 # find every problem, with line and marker
relate-gram load people.gram --db ./people    # load it into a Relate database
relate query --database ./people "MATCH (n) RETURN n"
relate-gram export --db ./people              # write it back out as gram
relate-gram fix people.gram --rel-type KNOWS  # correct what can be corrected

Install

Download a binary for macOS (Apple silicon or Intel) or Linux (x86-64) from the Releases page and check it against SHA256SUMS. Or build from source:

cargo install --git https://github.com/relatedb/relate-gram

As a Rust library

let report = relate_gram::load(&mut conn, source, &LoadSettings::default())?;
let text = relate_gram::export(&mut conn, &ExportSettings::default())?;

A load is one transaction: it completes or changes nothing. Identifiers in the file are kept as @id, so reloading an edited file updates elements instead of duplicating them.

Status

Version 0.1 is the first release: one graph space, no named graphs. Named graphs and typed tags are planned. See the changelog and the design documents.
