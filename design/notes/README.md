# Notes

Freeform notes that don't fit the RFC → ADR → spike process: explorations, naming, loose ends, things
worth remembering. A note has no required structure, no status workflow and no index table, and it
does not bind any decision. When a note turns into a question that needs an answer, write an RFC; when
it turns into a measurement, write a spike.

Name files `YYYY-MM-DD-short-title.md` so they sort by when they were written. Start each with a
one-paragraph statement of what it is about, written for someone who has found the repository for the
first time.
